## 2. 规划完成、待实现（三块）

### A. 技能系统（`docs/SKILL-SYSTEM.md` v5.1）

**抽卡三档**

| 结果 | 概率 | 自带 |
|---|---|---|
| 白板鼠 | 91.5% | 无线，技能随机 |
| 二级鼠 | 8% | 职业线 + **职业天赋必带** |
| 三级鼠 | 0.5% | 职业线 + 天赋 + 高一阶 |

- 10 抽保底一只 ≥二级；**十连内必有一只 ≥二级**；20 抽出双天赋保底。
- 技能携带（三档同表）：**0/1/2/3 = 30/42/22/6%**；等级 Ⅰ62 / Ⅱ30 / Ⅲ8。

**两处"会吃你东西"**

| 时机 | 吃什么 | 概率 |
|---|---|---|
| 白板 → 二级（转职） | 随机 1 个**技能** | **30%**（面板写明 70% 无损） |
| 炼妖 | 每条技能 | **8%** 被吃 → 未被吃则 70%/55% 继承 |
| 炼妖 | 每条额外天赋（槽2/3） | **2.5%** 被吃 → 未被吃则 70% 继承 |
| 炼妖 | 槽1 职业天赋 | **0%（免疫）** |

- 炼妖**必须二次确认**；技能数量**无上限**，同名合并升级（Ⅲ 封顶）。

**属性层（新增）**

| 属性 | 说明 |
|---|---|
| 物攻 | 普攻与物理技能的强度（现有 `baseDmg`） |
| **法强** | 魔法技能强度（tank 0.4× / blade 0.55× / shot 0.75× / **hex 1.6×** / care 1.0×） |
| 护甲 | 全队共享的**物理护盾**，只挡物理 |
| **物抗 / 魔抗** | 百分比减伤；我方初始值低（tank 10/3、hex 3/8、工鼠 2/2） |

```
物理 = 倍率 × 物攻 × (1 − 物抗) → 先扣护甲
魔法 = 倍率 × 法强 × (1 − 魔抗) → 不碰护甲
```

**铁律**：**一击只属于一种类型**（普攻恒物理；技能按自身类型；绝不物理+魔法混合）。
普攻与技能**两套独立计时**，互不占用。

**技能表（11 个，不绑职业，范围随等级）**

| 类别 | 技能（Ⅰ→Ⅲ 目标数） |
|---|---|
| 物理 4 | 冲击钻（1/1/1）· 横扫切削（**1→2→3**）· 穿甲钉（**1→2→3**，无视 50% 护甲）· 断头台（1/1/1，<30% 血 ×1.5） |
| 魔法 3 | 火球术（1/1/1 + 灼烧）· 冰霜新星（**1→2→3** + 攻速 **−5/−8/−12%**）· 闪电链（跳 **2→3→4**） |
| 增益 4 | 黄油护甲 · 加班冲刺 · 幸运签 · 糖分补给（范围 **自己 → 自己+1 → 全队**） |

**六道闸**：转职 30% 吃技能 / 炼妖按条吃 / 一次只放一个技能 / 冷却不随数量缩短 / 范围随等级 / 物理职业放魔法按低法强算。

### B. 敌方设计（`docs/ENEMY-DESIGN.md` v1）

| 原型 | 攻击方式 | 亮点 | 物抗/魔抗 |
|---|---|---|---|
| 破箱 | 冲撞击退 | 先破箱；破箱后「急躁」攻速 +15% | 25/5 |
| 穿甲 | 突刺（打 2 个） | **穿透 50% 护甲** | 15/10 |
| 拾荒 | 远程抛射 | **偷 2–5 金币**，15 秒撤离带赃款 | 5/20 |
| boss 质检 | 光束（穿透 3 个） | ≤50% 血「**超载**」：攻速 +30%、物抗 −10% | 18/18 |
| 粘胶 | 胶弹 | 我方攻速 **−15% 3 秒**；每 12 秒治疗同伴 10% | 5/28 |
| 自爆（新增） | 低血引爆 | 范围伤害 = 最大血 40%，1.2 秒引信 | 10/10 |

- 表现：**蓄力预警 0.45s 红圈**、类型色（物理橙/魔法蓝紫/治疗绿/偷钱金）、战况字幕；
- 编排：L1 破箱 → L2 穿甲 → L3 偷钱 → L4 混编 → L5 boss 超载 → L6 粘胶+自爆 → L7 起精英化；
- 防无解：每波最多 1 个特殊位、偷钱单次 ≤5 单局 ≤25、自爆不秒杀。

## 3. 实施顺序（合并排序，按依赖）

| 期 | 内容 | 依赖 | 验收标准 |
|---|---|---|---|
| **S1** | 属性层：法强 / 物抗 / 魔抗 + 伤害分流（物理/魔法）+ 一击单类型 | — | `detcheck` 胜率仍 100%、`rtcheck` L5/L6 不崩；日志能看到物理/魔法两色数字 |
| **S2** | 抽卡三档（8% / 0.5%）+ 10 抽保底 + 技能随机携带 + 详情页技能列表（只显示） | S1 | `gachacheck` 20k 抽分布对齐 91.5/8/0.5；保底触发率 <1% |
| **S3** | 转职 30% 吃技能 + 炼妖二次确认与逐条吃（8% / 2.5%） | S2 | `fusecheck` 5k 次：槽1 丢失 0；技能被吃率 ≈8%、天赋 ≈2.5% |
| **S4** | 4 个物理技能生效 + 目标数随等级 | S1–S3 | 单体技能只打 1 个；横扫 Ⅲ 打 3 个（日志核对） |
| **S5** | 3 个魔法技能（灼烧 / 冰霜 −5/−8/−12 / 闪电链 2→4） | S4 | 魔法伤害不吃护甲但吃魔抗；减速只刷新不叠加 |
| **S6** | 4 个增益技能（范围递增）+ buff 图标 | S5 | Ⅰ 级只作用自己、Ⅲ 级全队（日志核对） |
| **S7** | 炼妖技能继承合并 + 图鉴技能页 + 概率公示 | S2–S6 | 同名技能合并升级；公示与配置逐项一致 |
| **E1** | 敌方 6 个攻击函数骨架 + 蓄力预警 + 类型色 | S1 | 每种敌人出手方式可辨认 |
| **E2** | 破箱怒气 / 穿甲 / 拾荒偷钱撤离 | E1 | `foecheck`：偷钱金币变化正确、撤离带走、击杀返还 |
| **E3** | boss 超载 + 粘胶减速与治疗 | E2 | 超载窗口可测（物抗 −10%）；治疗每 12 秒一次 |
| **E4** | 自爆鼠（预警 + 范围伤害） | E3 | 1.2 秒引信；伤害 = 40% 最大血，不秒杀 |
| **E5** | 图鉴敌人页 + 编排微调 | E1–E4 | 六关各有主推亮点 |
| **S8** | 总配平（技能 + 敌方一起） | 全部 | L1 100% / L5 65–85% / L6 45–60%；天赋 0/1/2/3 四档跨度 ≤20pt |

> 顺序理由：**先把"伤害类型 + 抗性"这层地基铺好**（S1），技能与敌人都要在这层上结算；
> 敌人放到 S7 之后（E1 起），是因为敌人亮点大量依赖"物理/魔法"和"减速/治疗"这些新接口。
