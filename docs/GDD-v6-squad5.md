# GDD v6 · 五人小队 / 四阶职业 / 台上近身战

> 目标：把现在"3 只卡牌互拍数字"的战斗，改成**5v5 有位置、有射程、有职业分工的可视化战斗**，
> 并把"转职"从 2 档（二级 / 专精）扩成 **白板 → 二级 → 三级 → 四级**，每条线 3 次转职、每次换一把武器。
> **敌方（尖牙帮）走同一套规则**：也是 5 职业 × 4 阶、也换武器，只是捡废料当装备 —— 见 5.4 / 5.5 / 8.1。
> 本文件是**大纲**（先定结构与规则，不写代码）；数值是骨架，落地后一律用 `tools/levelsim.mjs` / `__rpgSimAt` 调。
> 现状依据：`game.json` 的 `rules.rpg`（`slots:3`、`squad`、`roster`、`foes`、`chapter`）、
> `tools/rpg.js`（`SZ` / 单位 / `realtimeTick` / `hurtFoe` / 资源分配）、`tools/shop.js`（`rats`/`line`/`tier`/`MODS`）。

---

## 一、这一版要解决的四个问题

1. **配合打不出来**：3 个格子只能"肉盾 + 一个输出 + 一个摇摆"，没有"前排顶、后排射、后排奶"的纵深。
2. **职业没分工**：现在所有单位都是"每 N 毫秒对最近敌人造成 X 伤害"，只有数值差，没有**行为差**。
3. **转职太短**：白板 → 二级 → 专精 就到底了，养成在第 4 关之后没有目标。
4. **台上没戏**：战斗是"卡上血条掉"，看不出近战在贴身、炮手在远处、法系在蓄力。

对应四条主线：**5v5 阵型**、**五职业 × 四阶（20 个形态）**、**四阶武器链**、**台上位置化战斗**。

## 二、阵型：5 上阵 + 板凳

- **上阵 5 格**（`rules.rpg.slots: 5`），板凳区不限（`SHOP.rats` 数组即板凳）。
- 编队操作沿用现在的"点一下选中 / 再点一下上下场"，只是从 3 格变 5 格；空位用虚线框提示。
- **不强制配比**，但给出推荐模板（新手引导用）：
  - `1 肉盾 + 1 近战 + 2 远程 + 1 增益`（均衡，教程默认）
  - `1 肉盾 + 3 远程 + 1 增益`（远程流，靠护甲拖时间）
  - `2 肉盾 + 1 近战 + 1 魔法 + 1 增益`（磨血流）
- **同种最多上 2 只**（防止 5 只奶自循环），这条写进 `rules.rpg.compose: { maxSameLine: 2 }`。
- 存档：`SHOP.squad` 从 `[0,1]` 长度 2 → 5；成长存档升 `v2`，迁移规则见第九节。

## 三、五职业 × 四阶（名字与定位）

T1 全部是**白板鼠**（同一个形态，用拳头）；T2 起分线。名字走"零食工厂工种"的调子，和现有 `LINE_NAME` 一脉相承。

| 线 | T1 白板 | T2 | T3 | T4 | 一句话定位 |
|---|---|---|---|---|---|
| 肉盾 `tank` | 白板鼠 | **铁皮鼠** | **铆甲鼠** | **堡垒鼠** | 吸引火力、减伤、站最前 |
| 近战 `blade` | 白板鼠 | **扳钳鼠** | **尖牙鼠** | **破城鼠** | 必须贴身、单体高爆、越打越破甲 |
| 远程 `shot` | 白板鼠 | **炮筒鼠** | **连发鼠** | **狙炮鼠** | 站后排、抛射、T3 起溅射 |
| 魔法 `hex` | 白板鼠 | **火种鼠** | **咒炉鼠** | **熔炉鼠** | 蓄力范围、挂灼烧/麻痹 |
| 增益 `care` | 白板鼠 | **医务鼠** | **药剂鼠** | **大医师鼠** | 治疗、护盾、加速、净化 |

（`tank/blade/shot/hex/care` 是新的线 id；现有 `wrench/driver/spring/medic/sack` 在迁移时映射到这几条线，见第九节。）

## 四、武器链：每次转职换一把，越往后越"华丽"

武器全部**代码矢量绘制**（不占包体），统一挂在 `WEAPONS[line][tier] = { name, draw(ctx,x,y,scale), len }`。
`len` 顺带当作近战"够不够得着"的判定宽度，让武器不只是贴图。

| 线 | T1（白板） | T2 | T3 | T4 |
|---|---|---|---|---|
| 肉盾 | 木锅盖 + 拳 | **铁盾 + 短棍** | **塔盾 + 钉锤** | **铆钉巨盾 + 战锤**（盾面出电弧） |
| 近战 | 拳 | **小刀** | **斧头** | **战锤 → 华丽大宝剑**（用户示例；T4 为发光大剑） |
| 远程 | 弹弓 | **短弩** | **连发弩**（三连发） | **加农炮**（后坐力 + 溅射关环） |
| 魔法 | 火柴 | **火把** | **电弧线圈** | **熔炉核心法杖**（环绕火星） |
| 增益 | 药膏罐 | **针筒** | **喷雾罐** | **医疗法阵旗**（脚下光环） |

> 近战按用户给的例子走满：小刀 → 斧头 → 战锤 → 大宝剑。T4 大宝剑加"剑风"拖尾，挥一次三段判定。

## 五、台上战斗：位置、射程、行为

### 5.1 舞台结构（竖屏 390×844）

```
y 0–96    顶部 HUD（关卡名 / 波次 / 存活）
y 96–344  战场
  ├ 敌排  y≈118–186   5 张卡，横排
  ├ 走廊  y≈186–250   投射物飞行 / 近战突进
  └ 我排  y≈250–318   5 张卡，横排
y 344–360 资源条（护甲 / 零件 / 能量）
y 360–660 5×5 棋盘
y 660–800 工具 ×3 + 大招 + 战况一行
```

横排 5 张卡：**卡宽 62、卡间 4** → `5×62 + 4×4 = 326 ≤ 344`（`W - 2·pad`）。卡内立绘 40×40，血条 4，充能条 3。
现有 `SZ.card 48 / 3v3 = 318` 的取值要改成 62，`cardH 76 → 84`（多一行武器名）。

> **实测修正（M6-3 已落地）**：竖屏要塞「两排卡 + 名字 + 战况 + 资源条 + 棋盘」，
> 卡宽 62 / 卡高 84 会把棋盘顶掉。最终取 **卡宽 48 / 卡高 66 / 立绘 40**，战况收成 1 行。
> 实测坐标（390×844）：舞台盒 `y 82–408`；敌排 `105–171`（名字 181/190）；走廊 `171–197`；
> 我排 `197–263`（名字 273/282）；战况行 `285–316`；资源条 `~390`；棋盘从 `420` 起。

### 5.2 每个单位新增的字段

`u = { line, tier, x, y, hp, hpMax, atk, atkMs, range, speed, state, target, cd, buffs }`

- `state`：`idle | approach | windup | release | recover | hurt | dead`
- `range`：`melee`（需贴到 12px 内）/ `mid`（舞台中线）/ `far`（不出原位，抛射）
- `speed`：近战突进 90px/s、肉盾 40px/s、远程 0（不移动）
- 攻击拆成 **抬手(windup) → 释放(release) → 收招(recover)**，命中在 `release` 那一帧判定
  —— 这才有"挥刀"和"炮口闪光"的观感，也是以后做"打断"的基础。

### 5.2.1 已落地（M6-1 第一刀）与两条实测约束

`tools/rpg.js` 里现在是：

```js
var STAGE = { gapMelee: 6, gapMid: 3, speed: 170, windupMs: 240, shotMs: 300 };
```

- **前压幅度被卡间距卡死**：3 人版本卡宽 48 + 间距 6，前压 40px 会直接盖住邻卡（实测截图里两个名字叠一起）。
  所以先取 **6px = 刚好贴边**；5 人版本卡宽 62 + 间距 4 时可放宽到 10px，**永远 ≤ 卡间距**。
- **抬手不能额外吃时间**：`release` 后把 `windupMs` 写回 `timerMs`，一轮仍等于 `atkMs`，
  所以改造前后 DPS 口径不变（`detcheck` 均伤 446 → 457、逐关胜率全 100%，见 CHANGELOG 0.9.3）。
- 走位只做一次（进场压上），不做"打完退回"，避免长期节奏漂移；中距离 `mid` 压一半，远程不动。

### 5.3 五种行为（这就是"职业功能"）

| 职业 | 目标选择 | 位移 | 攻击形态 | 特色机制 |
|---|---|---|---|---|
| 肉盾 | **优先被最近敌人锁定**（自带 `taunt`，单体伤害 60% 打到它） | 慢慢压到最前 | 近身 → 盾击 | 减伤 30%（T4 40%）+ 每 8s 一次盾击**打断**目标抬手 |
| 近战 | 最近的敌人 | **突进**（90px/s） | 近身挥砍，三段判定 | 暴击 15%；T3 起"破甲"（目标受伤 +10%，叠 3 层） |
| 远程 | 血量最低的敌人（T4 改为最高攻） | 原地（站后排） | **抛射物**：弩箭/炮弹飞 0.25–0.4s | T3 起三连发；T4 命中点 24px 内溅射 50% |
| 魔法 | 敌人最密集处（按 5 格窗口计数） | 站中排，蓄力时不动 | **蓄力 1.2s → 范围**（半径 60） | 火=灼烧(3s DOT)、电=麻痹(减速 40%)、熔炉=击退；消耗**能量** |
| 增益 | 友方血量比例最低者 | 站后排 | 无攻击（T4 有弱反击） | 治疗 / 护盾 30% / 加速 15% / 每 10s 净化一次减益 |

> 关键点：**远程不再"打数字"，而是发射物**；**近战必须真的走过去**；**法系有蓄力窗口，会被盾击打断**。
> 三条互相咬住，阵容搭配才有意义（例：两近战会被对面肉盾拖住，需要魔法清场；对面三远程需要我方肉盾顶住突进）。

### 5.4 敌方也进化：尖牙帮的五条线 × 四阶

敌方不是"换皮加血"，而是**同样 5 职业、同样 4 阶、同样换武器**（废料版：捡什么用什么）。
`foes` 表加 `line / tier / range / weapon`，`EVO` 与玩家共用一个阶数概念（T1–T4）。

| 线 | T1 | T2 | T3 | T4 | 武器链（废料） | 行为 |
|---|---|---|---|---|---|---|
| 肉盾 `crate` | **纸箱鼠** | **铁箱鼠** | **保险柜鼠** | **金库鼠** | 箱盖 → 铁皮盾 → 柜门 → 金库大门 | T1 破箱一次才露本体（保留这个梗）；T2 起要破两段；碾压式近身，自带 taunt |
| 近战 `shell` | **抛壳鼠** | **铰钳鼠** | **断牙鼠** | **血牙鼠** | 弹壳拳套 → 铰钳 → 断齿锯 → 大扳手锯 | 突进贴身；T3 起破甲；T4 每次命中回一小口血（嗜血） |
| 远程 `thief` | **拾荒鼠** | **弹弓鼠** | **痰盂炮手** | **废料迫击炮** | 石子 → 弹弓 → 痰盂发射器 → 迫击炮 | T1 每 7 秒改写盘上 3 格（保留）+ 扔杂物；T3 起抛物线溅射；T4 远程压制后排 |
| 魔法 `boss` | **质检机** | **电检机** | **高压检测塔** | **报废熔炉** | 扫描红光 → 电弧探针 → 高压线圈 → 熔渣喷口 | 蓄力 → 范围伤害（扫描/电弧/熔渣）；T2 起带麻痹，T4 留下一片"熔渣地"（站在上面持续掉血） |
| 增益 `glue` | **喷胶鼠** | **补丁鼠** | **焊接鼠** | **焊炉母鼠** | 胶管 → 补丁罐 → 焊枪 → 母胶巢 | 给同排回血 / 上盾；T3 起给敌方全体 +10% 攻速；T4 死亡时炸一地被治疗胶（我方踩上去减速） |

> 玩法上的意义：玩家升级到 T3 时，敌人也 T3 —— **你不会靠"堆数值"碾压，只能靠阵容与武器相克**。
> 例：对面 T4 金库鼠 + 焊炉母鼠（一个顶、一个奶），必须用法系 AOE 或近战破甲才推得动。

### 5.5 敌方怎么"进化"：三条驱动，不能只靠加血

1. **表驱动（主）**：关卡表给 `enemyTier`，与玩家预期阶数同步
   第 1–2 关 `T1`、3–4 关 `T2`、5–6 关 `T3`、7 关起 `T4`；第 2 轮起 `T4 + roundScale`（每轮 +15% 血/攻）。
2. **动态追赶（辅）**：开波时若"玩家阵容总阶数 − 敌方当前阶数 ≥ 3"，本波敌人升一档（最多到 T4）。
   作用：防止玩家早早 5 只 T4 后一路平趟；反之玩家落后时不降档（落后本来就该难）。
3. **精英标记（点缀）**：每波 1 只带 `elite`（阶 +1、血 −20%、名字前加「精英」、卡框描边金色）。
   只在第 4 关起出现，用来制造"这波先杀谁"的取舍。

**看得见的进化**：每升一阶换一件装备（箱盖→铁皮→柜门→金库门 / 弹壳→铰钳→锯→大扳手），体型 +6%，
名字与阶数直接印在卡上（`保险柜鼠 T3`）。**敌我共用同一套几何，只有调色板不同**（见 5.6），
所以"进化"靠**武器形状 + 卡框色阶（灰 → 铁蓝 → 锈红 → 暗金）+ 阶数文字**表达，不靠另做一套皮。
战报里也写阶数，玩家能立刻知道"打不动是因为对面是 T3 柜门，得先破甲"。

**波次脚本**改成"列阵容 + 阶数"：

```json
{ "name": "质检日", "enemyTier": 2, "waves": [
    ["crate", "crate", "shell"],
    ["boss", "crate", "glue"],
    ["shell", "shell", "thief", "glue"],
    ["boss", "boss", "crate", "shell", "glue"] ] }
```

不足 5 个就补空位（空位不代表安全，前排会继续推进）；`enemyTier` 可被动态追赶覆盖。


## 5.6 同模换色：敌我共用一套建模（**已定**）

结论：敌方**不做第二套美术**。一个 `drawUnit(line, tier, side, size)`，两套调色板 —— 形状、武器几何全部复用。
省下的量：40 个形态 → **20 个形态 × 2 调色板**，新增代码只有"调色 + 做旧"两个函数。
更重要的收益是**可读性**：玩家看到对面 T3 拿斧头的鼠，立刻知道"和我那只一样能破甲"，阶级语言统一了。

### 调色板

| 用途 | 我方（暖） | 敌方（尖牙帮，暗） |
|---|---|---|
| 毛色 | `#E8C08A` 琥珀 | `#8E8794` 灰紫（`h+8°, s−25%, v−28%`） |
| 肚皮 / 面部 | `#F5E6C8` | `#C6BFC9` |
| 描边 | `#8A6A46` | `#4E4650` |
| 强调（工具/高光） | `#E8AC50` 琥珀金 | `#B3402F` 锈红（去高光） |
| 眼睛 | `#2B2333` 深紫点 | `#FF2E3C` 核心 + `rgba(255,46,60,.45)` 外扩，1.2s 呼吸 |

### 四条硬约束（不满足就不能上）

1. **阵营靠框和底，不靠身体**：我方卡＝暖金描边 + 深紫底；敌方卡＝锈红描边 + 更暗底 + 右上角「尖牙」小徽记（8px）。
   10 张卡同屏时，0.2 秒内必须能扫出哪 5 张是自己的。
2. **朝向镜像**：我方朝右、敌方朝左（`ctx.scale(-1,1)`），双方"面对面"，镜像本身就是一个强提示。
3. **职业识别不靠颜色**：卡下 8px 职业图标（盾 / 刀 / 箭 / 法 / 十），敌我同图标、只用配色区分 —— 否则一套灰暗调会让五种职业糊成一片。
4. **状态色通道隔离**：受伤闪白、治疗闪绿、中毒闪紫一律做 80ms 叠加，**不许改基础调色**；
   否则"红=敌人"会被"红=受伤"污染，玩家会看错阵营。

### 废料感怎么来（不增加美术量）

同一个 `WEAPONS[line][tier]` 形状，加一个 `grit` 参数：
去掉高光层、描边换 `#4E4650`、叠 2–3 笔固定种子的锈斑/胶带/缺口。
→ 敌方 T3 和我方 T3 是**同一把斧头**，但一看就知道是捡来的。

### T4 / 精英额外处理

T4 敌方加一圈暗红雾光（`rgba(179,64,47,.18)` 外扩）+ 卡框暗金；我方 T4 是暖金高光。
精英＝卡框金色描边 + 名字前缀「精英」+ 阶数 +1 的同一形态（不再单独做模型）。

### 身份小道具（唯一的差异化投入，5 件）

纯换色会把"尖牙帮"抹平成一个队伍的镜像。低成本解法：**每条线给一个 10–14px 的小道具**挂在卡角，
我方不给（我方用金色队标区分）：

| 线 | 敌方小道具 |
|---|---|
| 肉盾 `crate` | 头顶半截纸箱屑 |
| 近战 `shell` | 肩上斜挎的弹壳串 |
| 远程 `thief` | 背上的破麻袋 |
| 魔法 `boss` | 耳侧的红色检测灯 |
| 增益 `glue` | 手上的胶管滴嘴 |

5 个小图形，代码各 3–5 笔，成本几乎为零，但"这是尖牙帮的人"一眼就成立。

### 代码落点（现有实现合并）

现在 `rpg.js` 里是两套绘制：`drawHamsterArt()`（1064 行附近）+ `drawFoeArt()`（1204 行附近），
武器/身体各画一遍。改造后：

```
drawUnitCard(x, y, unit, side, now)      // 卡框/血条/充能条：side 决定框色与底衬
  └ drawUnitArt(x, y, s, form, side, o)  // form = { line, tier }，全部几何只此一份
      ├ PALETTE[side]                    // 毛/肚/描边/强调/眼睛（见上表）
      └ WEAPONS[line][tier].draw(ctx, s, { tint: PALETTE[side].gear, grit: side === 'foe' })
```

`drawHamsterArt` / `drawFoeArt` 合并后约省 50 行，且以后加第 6 条线只写一次。
`window.__renderSlots()` 仍只输出我方暖色调（侧栏缩略图不变）。

## 六、转职与商店

## 七、三消 ⇄ 战斗的耦合（5 人版）

- **护甲**：全队共享盾（不变，`armorMax 45` 需上调到 ~60）。
- **零件**：私有槽轮转给"装配型"（近战/远程/肉盾 T3+），5 人时 `partsMax 18 → 26`。
- **能量**：进公共大招池 + 私有槽给法系/增益（`energyMax 100 → 130`）。
- 分配算法 `eatersOf` 从"2 人轮转"改成"按线权重轮转"：
  肉盾 1.0 / 近战 0.8 / 远程 1.0 / 魔法 1.2 / 增益 1.0（权重只影响私有槽的分配顺序，不改总量）。
- 大招（全厂爆产）伤害 `22` 固定改成 `14 + 4×上阵人数`（5 人 = 34），避免"少人反而更划算"。
