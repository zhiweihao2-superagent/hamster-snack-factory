## 1. 第四条硬决策（新增，和前三把锁一起守）

> **队伍变多，只加"资源消耗口"，不加"资源总量"。**

下方棋盘每步的产出是固定的（约 能量 +8 / 护甲 +4 / 零件 +2）。上场 3 只仓鼠 = 三张嘴抢同一份饲料，
所以**扩编不是变强，是变选择**：你必须决定这一关把钱和资源押在哪条线上。
这条一破（比如"上场仓鼠越多产量越高"），多单位立刻退化成数值通胀，三消的取舍感就没了。

## 2. 我方仓鼠小队

### 2.1 槽位与编队

- 场上 **3 个我方槽位**（左 1 = 前排，左 2 = 中排，左 3 = 后排），随章节解锁：
  章 1–2 只有 1 个槽，章 3 开第 2 个，章 5 开第 3 个。
- 商店里有「编队」页：从已拥有的仓鼠里选 1–3 只填槽，位置决定承伤顺序（前排先挨打）。
- 仓鼠**不会永久死亡**：被打倒 = 「累趴」，本关下场；关后在商店花 15 金币「修好」，或等下一关自动回满。

### 2.2 单位职责 = 吃哪种资源

每只仓鼠只认一种资源，这是让三色与队伍结构咬合的关键：

| 职责 | 吃 | 每点资源的动作 | 站位 |
|---|---|---|---|
| 🛡 承伤（Tank） | 护甲 | 每 6 护甲挡 12 点伤害，并把 1 点转给全队 | 前排 |
| 🔧 输出（Turret） | 零件 | 每 10 零件打一发 6 伤害（与炮台同源） | 中/后排 |
| ⚡ 技工（Skill） | 能量 | 每 25 能量放一次技能（15 AoE / 修复 / 增益） | 后排 |
| 被动（Passive） | 不吃 | 常驻效果（连击倍率 +0.5、掉落补格、暴击） | 任意 |

**为什么被动单位存在**：它是"资源不够时的第三选择"——上场 3 只全是要饭的，第 4 章就会卡死；
留一只不吃资源的功能鼠，才有"放弃一条线换稳定"的策略空间。

## 3. 品种树：基础仓鼠 + 装备 = 变种

**所有玩家开局只有 1 只「工鼠」**（白板，三资源各 +10% 效率，无技能）。
品种不是"抽卡抽出来的"，是**买装备装上去长出来的**——这是本作养成的核心手感：
你买的不是角色，是让某只仓鼠"转职"的那一件工具。

```
工鼠（基础·白板）
├─ 扳手 ──────────→ 铁皮鼠（承伤）── 铆钉甲 ──→ 液压鼠（承伤+反伤）
├─ 螺丝刀 ────────→ 炮筒鼠（输出）── 长管炮 ──→ 瓜子狙击鼠（输出+穿透）
├─ 弹簧 ──────────→ 速滑鼠（技工）── 电池组 ──→ 爆产鼠（技工+AoE）
├─ 医疗箱 ────────→ 扳钳鼠（修复）── 备用零件 ─→ 工程鼠（修复+护甲转换）
└─ 麻袋 ──────────→ 收集鼠（被动）── 大麻袋 ──→ 仓库鼠（被动+资源上限）
```

**升级即变种**：装上职业件后，仓鼠的名字、外观、职责一起换（图鉴里保留旧形象）。
二级装备（铆钉甲/长管炮…）只能在已有对应一级时购买，形成"一条线走到底"的深度。

## 4. 装备系统

每只仓鼠 **2 个装备位**：

- **职业位（1 格）**：决定品种，就是上面那棵树。装了才转职，可以拆下来换（拆下不退钱）。
- **通用位（1 格）**：数值件，谁都能装。给的就是"买或者替换"的操作乐趣：

| 通用件 | 效果 | 价 |
|---|---|---|
| 护目镜 | 该单位效率 +15% | 20 |
| 油壶 | 该单位行动间隔 -1 点资源 | 25 |
| 弹簧靴 | 该单位存活时全队 +5% 效率 | 25 |
| 铁牙套 | 该单位伤害 +2 | 30 |
| 小背包 | 该单位获得的资源 +2 | 30 |

**两个位的意义**：同一只铁皮鼠，(護目镜) 是刷效率、(铁牙套) 是刷反伤，
玩家会为了"我这关要硬扛"或"我这关要打穿"而反复换件——这就是每关一次商店的价值所在。

## 5. 商店（每关结束后，强制停留）

### 5.1 结构

```
┌───────────────────────────────────────┐
│  第 3 关 · 工厂开张        💰 78        │
├───────────────────────────────────────┤
│  [货架 1]      [货架 2]      [货架 3]   │   ← 每次刷新 3 格：装备/仓鼠/补给，随机
│  扳手 40       油壶 25       新仓鼠 35   │
├───────────────────────────────────────┤
│  我的仓鼠：工鼠(空/空)  工鼠(空/空)       │   ← 点开可装备/拆下/升级
├───────────────────────────────────────┤
│  编队：①铁皮鼠 ②炮筒鼠 ③—              │
├───────────────────────────────────────┤
│  [刷新 8]      [修好累趴 15]   [开工 ▶]  │
└───────────────────────────────────────┘
```

- **强制停留**：过关不自动进下一关，先看商店——这是节奏上的"呼吸点"，也是让玩家复盘上一关的地方。
- **刷新**：8 金币重掷 3 个货架（每关最多 3 次，防止无限刷到最优解）。
- **不卖的**：不卖数值直加（+100 血之类）、不卖跳过关卡。只卖**能力结构**。

### 5.2 金币经济

| 来源 | 数量 |
|---|---|
| 过关基础 | 12 |
| 剩余步数 | ×2/步 |
| 本关最高连击 | ×1/层 |
| 低伤奖励（护甲未被击穿） | +8 |
| Boss 关 | +20 |
| 重打已过关卡 | 只有基础的 30% |

| 支出 | 价 |
|---|---|
| 一级职业装备 | 35–40 |
| 二级职业装备 | 65–75 |
| 通用件 | 20–30 |
| 新仓鼠（裸工鼠） | 35 |
| 修好累趴 | 15 |
| 刷新 | 8 |

**曲线意图**：一章 3 关总收入约 60–90 金币 → 一章能买 **1 件二级** 或 **2 件一级 + 1 通用件**。
第 3 章开始出现"槽位比仓鼠多"的局面（3 槽但要养 3 只），钱永远不够——这就是长线目标。

## 6. 敌方上限与同屏容量（回应"双方可上场数量随关卡增长"）

| 章 | 我方槽位 | 敌方同屏 | 敌方排队 | 同屏单位总数 |
|---|---|---|---|---|
| 1 工厂开张 | 1 | 1 | 0 | 2 |
| 2 第一笔订单 | 1 | 2 | 0 | 3 |
| 3 零食试吃会 | 2 | 2 | 1 | 5 |
| 4 挑食的贵客 | 2 | 3 | 1 | 6 |
| 5 零食节 | 3 | 3 | 2 | 8（含排队指示条） |

**为什么敌方最多 3 个同屏**：竖屏 390 宽，一个单位连血条约 56px，我方 3 + 敌方 3 = 336px，
放得下且不挤。第 4 个起走**排队条**（右侧小图标 + 倒计时"还有 2 步进场"），
Boss 召唤小兵也进排队——既满足"数量增长"的爽感，又不把竖屏撑爆。

## 8. 局内流程与状态机

```
title → shop(编队) → play(第 1 波) → [三选一临时增益] → play(第 2 波) → play(第 3 波)
      → 结算(金币) → shop → play(下一关) → … → chapterClear → shop
```

`S.phase` 取值：`title | shop | play | pick(波间临时增益) | win | lose`
（v2 的 `waveClear` 并入 `pick`，`chapterClear` 改为结算页上的"章末"标记）

**波间三选一（保留但降级）**：随机 3 张**本关有效**的临时卡，三选一，例如
「本关护甲上限 +20」「本关零件产出 +50%」「本关开局能量 50」。
它和商店的区别：**临时 vs 永久**，前者是临场对策，后者是长线构筑，两套随机奖励不会打架。

### 8.1 与三消的接口（不改核心）

| 现有 | 变化 |
|---|---|
| `commitClear()` 里的 `perType` | → 汇总为 `pools = {energy, armor, parts}`，再按**上场单位的诉求**分流 |
| 分流规则 | 同一资源池由多只单位共用，按"谁先充能满谁先动"（队内顺序） |
| `afterResolve()` | 每步末：池子结算 → 单位行动判定 → 敌方充能 +1 → 敌方行动 |
| `useTool()` | 技能仍不花步数，但**伤害结算改成对"当前目标单位"**（我方技能打敌方、敌方技能打我方） |
| `drawGiftPanel()` | → `drawStage()`：画两排单位卡、资源池条、弹道、飘字、排队条 |
| `chooseUpgrade()` | → `openShop()`（新 phase），三选一卡走 `pickTemp()` |

**核心纪律不变**：玩家只碰下方棋盘 + 商店/编队两个菜单，战斗全自动。

## 10. 里程碑（在 v3 之上重排）

| 阶段 | 内容 | 验收 |
|---|---|---|
| **M1（1–2 天）** | 舞台替换 + 三资源池 + 步数即时间轴 + 1 只工鼠 + 纸箱鼠 + 胜负 | playtest 60s 无错，能打完一关 |
| **M2（2–3 天）** | 单位卡渲染 + 3 条职业线（铁皮/炮筒/速滑）+ 资源分流 + 敌方排队 | 上场 2 只时资源明显不够，能感到取舍 |
| **M3（3 天）** | 商店（货架/刷新/装备/编队/修好）+ 金币结算 + 波间临时卡 | 一关的钱刚好买不起想要的两件 |
| **M4（2 天）** | 5 章 15 关数据 + 5 条线全开 + 两 Boss + 存档（金币/仓库/编队） | 全流程可通关，存档可续 |
| **M5（1 天）** | 微信包 + 提审材料 + 看广告补金币/补步数 | < 4 MB，胶囊不挡顶栏 |

**先做 M2 再看要不要继续**：多单位 + 资源分流是全案最可能翻车的地方（手感一变，前面全白做），
所以把"上场 2 只能不能玩得爽"设成第一个生死验收点。

## 11. 风险与取舍

1. **多单位 = 认知爆炸**：所以每只仓鼠只认一种资源、只显示一条资源条、技能只有一个。任何"双资源单位"的建议一律否掉。
2. **商店打断节奏**：每关一次、最多两屏翻页、默认焦点在「开工」。不做多层 tab、不做商城/礼包/限时。
3. **钱不够会劝退**：重打给 30% 金币 + 修好只要 15，保证"卡关也能靠刷两把过去"。
4. **平衡爆炸**：品种 11 个 + 装备 18 件 = 198 种组合，**只调 5 条线的三档数值，不做逐件精调**；用 `regress` 的模拟批量跑（每档 50 局）。
5. **竖屏塞 8 单位**：同屏硬上限 6，其余进排队条；这是我给的空间答案，不要试图挤第 7 个。
6. **过审用词**：仓鼠被打倒是「累趴/停机待修」，敌人是「偷零食」，结算按钮「重新开工」；不出现击杀、死亡、血液。

## 12. 待定项（推荐值，可直接拍）

| 问题 | 推荐 | 理由 |
|---|---|---|
| 新仓鼠买来是白板还是带一级装备？ | **白板工鼠** | 装备才是养成的核心，角色本身应是"容器" |
| 职业件能拆下来给别的仓鼠吗？ | **能，不退钱** | 允许改构筑，玩家才敢在第一件上试错 |
| 上场不满 3 只时资源会不会溢出？ | **上限硬顶**（护甲 60/能量 100/零件 30） | 溢出惩罚过重会让玩家不敢换人 |
| 商店要不要卖"重抽编队"？ | **不卖**，编队随时可改且免费 | 位置调整是策略，不该收费 |
| 被动单位（收集鼠）值不值得买？ | **值得**，第 4 章起资源被三线分食时它会变成最优解 | 给"放弃一条线"留一条体面出路 |
