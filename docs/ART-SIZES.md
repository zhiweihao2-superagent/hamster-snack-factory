# 美术尺寸规范（M2 起生效）

所有数值以**逻辑像素**为单位，基准竖屏 390×844（iPhone 13/14 尺寸），DPR 由 `resize()` 处理。
参数集中在 `game.js` 的 `SZ` 对象里（由 `tools/rpg.js` 提供），**改一处全动**，不要在绘制函数里写死数字。

## 1. 舞台（原礼盒图案区）

| 项 | 值 | 说明 |
|---|---|---|
| 区域 | `x = L.pad`（≈17）、`y = L.giftY`（≈82）、`w = W - 2×pad`（≈356）、`h = L.giftH`（≈321） | 由 `layout()` 算出 |
| 圆角 / 描边 | 12 / 1px `#4a4160` | |
| 标题行 | y + 17，字号 11，左=章节名，右=「尖牙帮 · 波 n/N」 | |
| 卡片顶 | `stageCardY() = giftY + 34` | |
| 传送带 | 卡片底部 `cardY + cardH - 6`，高 10 | 纯装饰 |
| 战况面板 | 底部对齐 `y + h - 92`，宽 `w - 20`，3 行 × 12 + 18 | |

## 2. 单位卡（我方 / 敌方共用尺寸）

| 项 | 值 | 备注 |
|---|---|---|
| 卡宽 × 卡高 | **48 × 76** | 宽度按"最挤 3v3"定死：6×48 + 5×6 = 318 ≤ 344，**不能再放大** |
| 圆角 | 10 | |
| 角色绘制区 | 46 × 46，位于卡内 `y + 6`，水平居中 | 矢量图画满 46×46 的方框 |
| 卡内血条 | 宽 40、高 4，内边距 4 | 我方 `#79c98a`，敌方 `#d96d55` |
| 卡内充能条 | 宽 40、高 3，紧贴血条上方 | 我方零件 `#c7b6ff` / 能量 `#ffd98a`；敌方出手倒计时 `C.amber` |
| 名字 | 卡下 10px，字号 8，居中 | |
| 读数 | 卡下 19px，字号 8 | 我方 `充能/需求`；敌方 `N 步`；阵亡写「已击退 / 累趴」 |
| 间距 | 6 | |
| 阵亡遮罩 | `rgba(20,16,28,.55)` 整卡覆盖 | |

我方槽从左 `pad + 10` 起排；敌方槽从右对齐，右边界 `W - pad - 10`。

## 3. 增援 / 资源条 / 按钮

| 项 | 值 |
|---|---|
| 增援小卡 | 20 × 20，圆角 5，间距 2，横排，右对齐到 `x + w - 12`，底对齐 `y + h - stripH - 26` |
| 资源条 | 高 7，圆角 3.5，两条各占 `(w - 36 - 44) / 2`；标签 `护甲 32/60` 字号 9，画在条上方 3px |
| 大招按钮 | 直径 44 圆形，右对齐 `x + w - 44 - 10`；外环 3px，内部环形进度 3px，中心字 10~11 |
| 伤害飘字 | 字号 13（≥10 点伤害用 16），上飘 26px，760ms 淡出 |
| 波次横幅 | 字号 `W × 0.052`，居中 `y + h × 0.52`，1100ms |

## 4. 棋盘（未改动）

沿用原工程：`cs = floor(min((W - 2×pad) / 5, H × 0.46 / 5))`（390 宽下 ≈71），
方块圆角 `cs × 0.16`，内边距 `cs × 0.055`。**RPG 改造不碰棋盘渲染。**

## 5. 美术替换时的对齐要求

将来接位图（AI 出图 / 手绘）时，每张图按下面的框出图即可无缝替换：

| 槽位 | 画布 | 内容占比 | 注意 |
|---|---|---|---|
| 仓鼠（4 种线） | 92×92 | 角色占 88%，四周留 6% 透明 | 脚底对齐画布底部 6% 处（传送带线上） |
| 敌人（纸箱/抛壳/拾荒） | 92×92 | 同上 | 面部朝左（面向我方） |
| Boss | 128×128 | 角色占 84% | 与普通敌人同底对齐 |
| 车间背景 | 712×300（@2x） | 传送带位于高度 45% 处 | 可选，不接则用代码背景 |

**为什么是 92×92 而不是 46×46**：卡内绘制区 46 逻辑像素，2× 出图给高分屏用；
项目里所有图片槽位尺寸以 `game.json` 的 `slots[].size` 为准，接图时同步改那里。
