# 技能系统 + 属性（物攻/法强/物抗/魔抗）—— 规划（v5）

> v5 改动（按你这一轮的七条）：
> 1. 白板→二级**不是必吃技能**，改成概率；
> 2. 炼妖里**所有条目都有概率被吃**（技能概率大、天赋概率小），不再是"只吃额外天赋"；
> 3. 魔法**不再直打生命** —— 加 **物理抗性 / 魔法抗性** 两个属性；
> 4. 物理职业吃到魔法技能照样能放，走**法术强度**结算，所以"能放但打不高"；
> 5. 炼妖吃天赋**必须二次确认**；
> 6. 冰霜减速压到 **−5% / −8% / −12%**；
> 7. 魔法技能也**不是全屏**，同样按等级增加命中单位。

---

## 1. 属性体系（新增）

每只仓鼠 / 每个敌人都有一组数：

| 属性 | 含义 | 说明 |
|---|---|---|
| **物攻** `atk` | 物理技能与普攻的强度 | 现有 `baseDmg` 就是它 |
| **法强** `mag` | 魔法技能的强度 | 新增；由职业线决定高低 |
| **护甲** `armor` | 全队共享的**物理护盾** | 现有 `R.armor`；只挡物理 |
| **物抗** `resP` | 物理减伤 % | 新增 |
| **魔抗** `resM` | 魔法减伤 % | 新增 |

### 结算公式（统一入口）

```
物理伤害 = 倍率 × 物攻 × (1 − 目标物抗)   → 先扣护甲，溢出才扣血
魔法伤害 = 倍率 × 法强 × (1 − 目标魔抗)   → 不碰护甲，直接扣血（但有魔抗抵消）
```

- 护甲是"物理护盾"，所以魔法**绕过护甲**，但**不是白打**——魔抗顶上来；
- 敌人也有抗性：铁箱鼠类 **物抗高、魔抗低**；喷胶鼠 **魔抗高**；质检机（boss）两项都中等。这样"物理/魔法"是真选择。

### 我方初始抗性（低，只做"体质差异"，不做主要防线）

| 职业 | 物抗 | 魔抗 | 说明 |
|---|---|---|---|
| 肉盾 tank | **10%** | 3% | 天生抗打，但不抗法 |
| 近战 blade | 6% | 3% | |
| 远程 shot | 4% | 4% | 均衡 |
| 魔法 hex | 3% | **8%** | 抗法不抗物理 |
| 增益 care | 5% | 5% | |
| 白板工鼠 | 2% | 2% | |

- 数值刻意压得低：抗性是"体质差异"，主要防线仍是护甲（物理）+ 技能/天赋；
- 天赋与增益技能可以在这之上再加（如黄油护甲提护甲、护罩类提抗性留作后续扩展点）。

### 各职业的物攻/法强比例（仓鼠侧）

| 职业 | 物攻 | 法强 | 直觉 |
|---|---|---|---|
| 肉盾 tank | 1.0× | **0.4×** | 打不动法术 |
| 近战 blade | 1.0× | 0.55× | 偏物理 |
| 远程 shot | 1.0× | 0.75× | 均衡略偏物理 |
| 魔法 hex | 0.7× | **1.6×** | 法术主输出 |
| 增益 care | 0.8× | 1.0× | 偏辅助 |

> 于是"物理职业吃到魔法技能"= 能放，但只按它 0.4–0.75 的法强算 —— **不会浪费，也不会超模**。

## 3. 白板 → 二级：**30%** 概率吃一个技能

| 时机 | 发生什么 | 概率 |
|---|---|---|
| 转职（白板→有二职业） | 获得**职业天赋**（槽1）；**随机顶掉 1 个技能** | **30%**（有技能时掷一次） |
| 二级 → 三级 / 四级 | 只升阶，不掷 | — |

所以"转职清空技能风险"只是概率上的，**不是保底**；面板会明写 `本次转职 70% 不损失技能`。

## 4. 炼妖：所有条目都可能被吃（技能易、天赋难）

每条独立结算，最多吃 1 条技能 + 1 条额外天赋：

| 条目类型 | 被吃概率 | 再判继承 |
|---|---|---|
| 主鼠技能（每条） | **8%** | 未被吃 → **70%** 保留 |
| 副鼠技能（每条） | **8%** | 未被吃 → **55%** 保留 |
| 主鼠额外天赋（槽2/3，每条） | **2.5%** | 未被吃 → **70%** 保留 |
| 主鼠槽1 职业天赋 | **0%（免疫）** | 100% 保留 |
| 同名技能/天赋 | — | 合并升级（Ⅲ 封顶） |

- **必须二次确认**：点「炼妖」先弹确认页，写清
  `可能失去：技能 8%/条 · 额外天赋 2.5%/条 · 槽1 免疫`，再点「确认炼妖」才扣钱；
- 结果卡与战况逐条明写：`失去了 冲压Ⅱ` / `失去了 复苏Ⅱ`；
- 技能数量**仍无上限**。

## 4.5 一击只属于一种伤害类型（**绝不混合**）

**结论：随机切换 —— 每一击要么是物理、要么是魔法，不存在"物理 + 魔法同时结算"。**

| 场景 | 这一击的类型 | 用哪个属性 |
|---|---|---|
| 普通攻击 | **恒为物理** | 物攻 → 吃物抗、扣护甲 |
| 施放物理技能 | 物理 | 物攻 → 吃物抗、扣护甲 |
| 施放魔法技能 | 魔法 | 法强 → 吃魔抗、**不碰护甲** |

- 一只鼠同时带物理技能和魔法技能时：技能冷却到点后从"就绪池"里挑一个施放
  （**伤害技能优先、等级高优先**，同级则**随机**）—— 这就是"随机切换"；
- **不存在**一次性物理+魔法混合结算，也不做"双属性各按一半"这种折中；
- 因此"物理职业吃魔法技能"的实际表现是：**平时用物理普攻/物理技能，轮到魔法技能时按它偏低的法强打一发魔法（吃魔抗）**。

## 4.6 普攻与技能是两套计时（完全分开）

| | 普攻 | 技能 |
|---|---|---|
| 计时 | 自己的 `atkMs`（2.4–3.2 秒） | 自己的冷却（6–14 秒） |
| 类型 | **恒为物理**（远程也是物理弹道） | 按技能自身：物理 / 魔法 / 增益 |
| 强化 | 资源满时打「强化弹」（现有机制，仍属物理） | 不受强化弹影响 |
| 频率 | 一直在打 | 冷却到点才放，**一次只放一个** |

- 两者**互不占用**：同一只鼠可以在同一秒「打一发普攻 + 放一个技能」；
- 技能**不会顶替**普攻，普攻也**不会**被技能冷却拖慢；
- 特例：增益系（care）的强化弹是**治疗**，它占的是普攻位，不是技能位；
- **配平含义**：技能是「额外叠加的一层」，所以倍率按 1.0–2.6× 配（不是 4×+），
  否则普攻 + 技能会直接把 DPS 翻倍；实测偏强时先动 `rules.skills.cdMul`（1.0 → 1.15 → 1.3）。

**`game.json`**
```json
"rules": {
  "combat": { "resP": 0.0, "resM": 0.0 },
  "ratStats": { "tank": {"magMul":0.4}, "blade": {"magMul":0.55}, "shot": {"magMul":0.75}, "hex": {"magMul":1.6}, "care": {"magMul":1.0} },
  "foeRes": { "crate": {"resP":0.25,"resM":0.05}, "shell": {"resP":0.15,"resM":0.10}, "thief": {"resP":0.05,"resM":0.20}, "boss": {"resP":0.18,"resM":0.18}, "glue": {"resP":0.05,"resM":0.28} },
  "skills": { "enable": true, "cdMul": 1.0, "list": { "...": {} } },
  "gacha": { "rat": { "tier2": 0.08, "tier3": 0.005, "tier2Pity": 10 } },
  "fuse": { "eatSkill": 0.08, "eatTalent": 0.025 },
  "promote": { "eatSkillChance": 0.45 }
}
```

**`tools/rpg.js`**
- `hurtFoe(foe, dmg, kind, attacker)`：`kind: 'phys' | 'mag'`；
  - phys：`dmg × (1 − resP)` → 先扣护甲；
  - mag：`dmg × (1 − resM)` → 直接扣血；
- `applyUnitDamage(u, dmg, kind)`：敌人打我方同理（我方也有 resP/resM，默认 0，靠天赋/技能提升）；
- `unitMag(u)`：按 `ratStats[line].magMul × baseDmg` 算；
- `pickTargets(skill, lv, from, list)`：按等级取 1/2/3/4 个目标；
- `castSkill()` + 状态（灼烧已有、冰霜新增 `foe.slowUntil/slowMul`，在 `foeTimer` 里乘）。

**`tools/shop.js`**
- 抽卡三档 + 保底；技能携带；
- 转职 30% 吃技能（面板写概率）；
- 炼妖二次确认 + 逐条被吃概率 + 结果明写；
- 详情页：属性块加 **法强 / 物抗 / 魔抗**；技能列表带类型标签与目标数；
