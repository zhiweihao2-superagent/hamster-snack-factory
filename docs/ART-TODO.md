## 三、规格约定（给做美术的人）

1. **尺寸**：我方/敌方一律 64×64；图标 16×16（可另出 32×32 版）；UI 插画按上面单列；
2. **透明**：`alpha` 只用 0 / 255（二值），不要半透明边缘；
3. **朝向**：我方**朝右**、敌方**朝左**；
4. **锚点**：脚底对齐画布底部、身体水平居中（下沿留 2–3px 透明）；
5. **帧命名**：`idle-1.png / idle-2.png / action-windup.png / action-strike.png / hop-air.png`；
6. **调色**：暖棕/橙毛 + 奶油脸，轮廓线 `#3a241e`；敌方灰毛 + 红眼；
7. **运动**：`action-strike` 出手帧要有"身体前倾 + 武器伸展"，`hop-air` 要有明显离地。
