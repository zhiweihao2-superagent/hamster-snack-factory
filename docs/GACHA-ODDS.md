# 概率公示（Gacha Odds）

> 本文件是《仓鼠零食工厂》所有随机机制的概率说明，和 `game.json` 里的配置逐项对齐。
> 游戏内「抽奖」页也会直接显示同样的数字；提审问卷请照此填写。
> **本作不存在任何人民币充值，随机机制只消耗游玩产出的金币与碎片。**

最后核对版本：**v0.9.42**（`game.json` → `rules.gacha` / `rules.shard` / `rules.talents`）

---

## 1. 仓鼠池（出仓鼠 + 天赋 + 技能）

| 项 | 值 |
|---|---|
| 单抽 | **60 金币**（或 12 碎片） |
| 十连 | **540 金币**（9 折） |
| **保底** | 累计 **10 抽**未出 ≥二级 → 这一抽强制二级；**十连内必有一只 ≥二级** |

### 1.1 档次
| 结果 | 概率 | 自带 |
|---|---|---|
| **白板鼠** | **91.5%** | 无职业线；天赋与技能随机 |
| **二级鼠** | **8%** | 固定职业线 + **本职业天赋必带**；技能同样随机 |
| **三级鼠** | **0.5%** | 同上，高一阶（省两张转职证） |

> 实测（20 000 抽）：白板 **91.6%** / 二级 **7.8%** / 三级 **0.6%**

### 1.2 天赋（同一只鼠最多 3 条）
| 槽位 | 概率 |
|---|---|
| 单天赋 | 82% |
| 双天赋 | 13% |
| 三天赋 | 5% |

等级独立掷：**Ⅰ 62% / Ⅱ 30% / Ⅲ 8%**（Ⅲ 级抽到会全屏播报）。

### 1.3 技能（白板 / 二级 / 三级同一张表）
| 技能数 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 概率 | **30%** | **42%** | **22%** | **6%** |

- 从 **11 个技能**（4 物理 / 3 魔法 / 4 增益）里随机，**不绑职业**；
- 每个技能等级独立掷：**Ⅰ 62% / Ⅱ 30% / Ⅲ 8%**；
- 实测（20 000 抽）：0 **30.1%** / 1 **42.0%** / 2 **22.0%** / 3 **5.9%**。

## 2. 道具池

| 项 | 值 |
|---|---|
| 单抽 | **20 金币**（或 5 碎片） |
| 十连 | **180 金币**（9 折） |
| 保底 | **十连内必出 1 张转职证**（单抽累计第 10 次也必出） |

| 产出 | 概率 | 说明 |
|---|---|---|
| 金币 +30 | **40%** | 直接返还 |
| 碎片 ×1 | **30%** | |
| 转职证 | **25%** | 优先给"还能升阶"的仓鼠；若全队都已满阶，折 **2 碎片** |
| 大奖 | **5%** | 金币 +90 且 碎片 +3 |

## 3. 碎片（不是抽奖，是确定性兑换）

| 项 | 值 |
|---|---|
| 分解仓鼠 | `2×天赋槽数 + 1×(总等级 − 槽数)`，上限 12。<br>例：单天赋Ⅰ **2** / 双天赋Ⅰ **4** / 三天赋Ⅲ **12**；无天赋白板鼠 **1** |
| 兑换 | 道具抽 **5 碎片** / 仓鼠抽 **12 碎片**（按池分别定价） |
| 其他来源 | 道具池 30% 出 1 个、大奖 3 个、炼妖无继承兜底 3 个 |

---

## 4. 炼妖（合成）

| 项 | 值 |
|---|---|
| 消耗 | **30 金币**，副鼠消失 |
| 主鼠槽1 天赋 | **100% 保留**（等级取两只中较高） |
| 主鼠其它天赋 | 每条 **55%** 保留 |
| 副鼠所有天赋 | 每条 **45%** 保留 |
| 槽位上限 | 3（超出按等级从高到低取） |
| 兜底 | 一条额外天赋都没继承 → 返还 **3 碎片** |

> 实测（5 000 次，双天赋 × 双天赋）：继承 0 条 **13.6%** / 1 条 **39.6%** / 2 条 **46.7%**；槽1 从未丢失。

## 5. 局内随机（不影响货币）

| 机制 | 概率 |
|---|---|
| 波间补给三选一 | 7 张卡池等概率抽 3 张（单卡出现率 3/7 ≈ **42.9%**），只在本关生效，免费 |
| 押注卡 | 波间必现一张（金币 ≥ 20 时）。押 10–60 金币，本波全员无伤返 2 倍，任一仓鼠掉血没收 |
| 关卡随机事件 | 第 2 关起 **28%**，第 4 关起 **45%**；从 3 个事件中等概率抽 1 个 |
| 稀有掉落 | 普通敌人 **10%** 掉 25 金币；boss **100%** 掉 40 金币 |

## 7. 与"付费"的关系

- 本作**没有**任何人民币购买入口，金币与碎片**只能通过游玩获得**；
- 不存在"付费提高概率""付费保底""限时折扣礼包"等机制；
- 所有保底计数存于本机存档，清除缓存会重置（这一点已在游戏内说明）。

## 8. 技能与"被吃"概率（随机机制补充）

> 本作没有付费影响概率的机制，以下均为游玩过程中的随机判定。

| 时机 | 判定 | 概率 |
|---|---|---|
| 转职（白板 → 二级） | 随机失去 1 个已携带技能 | **30%**（有技能时掷一次，70% 无损） |
| 炼妖（合成） | 主/副鼠**每条技能**被吃 | **8% / 条** |
| 炼妖（合成） | 主鼠**每条额外天赋**（槽2/3）被吃 | **2.5% / 条** |
| 炼妖 | 槽1 职业天赋 | **0%（免疫）** |
| 炼妖 | 未被吃的技能 | 主鼠 **70%** / 副鼠 **55%** 保留，同名合并升级（Ⅲ 封顶） |
| 炼妖 | 一条额外天赋都没继承 | 返还 **3 碎片** |

> 实测（4000 次炼妖）：技能被吃 **8.17%** / 额外天赋被吃 **2.83%** / 槽1 丢失 **0**。

## 9. 敌方随机（局内表现）

| 机制 | 概率 / 数值 |
|---|---|
| 精英敌人 | 每波最多 1 只，**12%**；血 ×1.6、攻 ×1.25、赏金 ×2（第 1 关第 1 波不刷） |
| 关卡随机事件 | 第 2 关起 **28%**，第 4 关起 **45%** |
| 拾荒鼠偷钱 | 每次命中 2–5 金币，单局上限 25；存活 15 秒撤离并带走 |
| 粘胶鼠治疗 | 每 12 秒给血最少的同伴回 10% |
| 质检机超载 | 血量 ≤50% 触发（出手更快、物抗 −10%） |
