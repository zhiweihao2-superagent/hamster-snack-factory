# 天赋 / 抽卡 / 碎片 / 合成 —— 系统规划（v3）

> v3：十连优惠（两池都有）、Ⅲ 级播报带分享按钮、去掉洗点。
>
> v2 改动：难度池碎片产出下调（3 个 → **1 个**）、分解回收下调、**碎片按池分开定价**、
> 三天赋概率 2% → **5%**、**去掉合成保底券**、配件全砍、槽2/3 允许跨职业。

---

## 0. 结构

```
仓鼠
 ├─ 职业线 line（tank / blade / shot / hex / care）
 ├─ 天赋槽 talents[3]：槽1 本职业天赋（必带）｜槽2、槽3 可跨职业
 └─ 阶 tier（转职证系统，不变）

抽卡：道具池 20💰 ｜ 仓鼠池 60💰
碎片：分解仓鼠 / 道具池产出；**兑换按池定价**（道具 5 碎片、仓鼠 12 碎片）
合成：主鼠槽1 固定，其余随机继承；无保底券
```

配件（护目镜 / 油壶 / 小背包 / 铁牙套 / 垫片）**整组删除**，旧存档按 **2 碎片/个** 折算。

| 线路 | 天赋 | Lv1 | Lv2 | Lv3 |
|---|---|---|---|---|

## 2. 天赋槽概率（v2）

| 结构 | 概率 | 说明 |
|---|---|---|
| 单天赋 | **77%** | 只有槽1 |
| 双天赋 | **18%** | 槽1 + 槽2（可跨职业） |
| **三天赋** | **5%** | 槽1+2+3（v2 从 2% 提到 5%） |

## 3. 抽卡

### 3.1 道具池（现有摇奖机）

- 单抽 **20💰**
- **十连 180💰（9 折）**，且十连内必出 1 张转职证（沿用现有十连保底）

| 产出 | 概率 |
|---|---|
| 金币 +30 | 40% |
| **碎片 ×1** | **30%**（v2：原来 3 个太多） |
| 转职证（选中鼠能升则升） | 25% |
| 大奖：+90 金币 + **3 碎片** | 5% |

### 3.2 仓鼠池（新）

- 单抽 **60💰**
- **十连 540💰（9 折）**

随机一条**当前未满编上限**的职业线 → 白板鼠（tier 1）→ 掷天赋 → 入场动画 → Ⅲ 级播报。

| 结果 | 概率 |
|---|---|
| 单天赋 | 77% |
| 双天赋 | 18% |
| 三天赋 | 5% |

**保底**：累计 20 抽未出"双天赋+"，第 20 抽强制双天赋且槽2 ≥ Ⅱ（计数存档持久化，可显示"距保底 N"）。
十连会一次性推进保底计数 10 次，所以"两次十连"必出双天赋。

## 4. 播报（Ⅲ 级）

全屏金色横条 `✦ Ⅲ级天赋 · 硬化 ✦ 铁皮鼠`，2.4 秒 + 专属音效；战况留痕一行。

**分享按钮（v3 新增）**：横条右侧一个「分享」按钮，点了走平台能力——
- 微信小游戏：`wx.shareAppMessage({ title: '我抽到了 Ⅲ 级硬化！', imageUrl: 截图 })`；
- H5 / 本地：退化为复制文案 + 屏幕提示「已复制」。
按钮只在这次播报期间出现，2.4 秒后随横条一起消失；错过可以在「图鉴 · 天赋页」里再点一次分享。

## 5. 碎片（v2 重定价）

### 5.1 获取

| 来源 | 数量 |
|---|---|
| 道具池 30% | **1** |
| 道具池大奖 5% | **3** |
| 分解仓鼠 | 见下 |
| 合成失败（无额外天赋继承） | 返还 3 |

**分解公式（v2，比原来低一半）**：`碎片 = 2 × 槽数 + 1 × (总等级 − 槽数)`，上限 12
（Ⅰ=1、Ⅱ=2、Ⅲ=3 计）

| 例子 | 碎片 |
|---|---|
| 单天赋 Ⅰ | 2 |
| 单天赋 Ⅱ | 3 |
| 单天赋 Ⅲ | 4 |
| 双天赋（Ⅰ/Ⅰ） | 4 |
| 双天赋（Ⅰ/Ⅲ） | 6 |
| 三天赋（Ⅰ/Ⅰ/Ⅰ） | 6 |
| 三天赋（Ⅲ/Ⅲ/Ⅲ） | 12 |

### 5.2 消耗（**按池分开定价**）

| 用法 | 碎片 |
|---|---|
| 换 1 次**道具池**（等价 20💰） | **5** |
| 换 1 次**仓鼠池**（等价 60💰） | **12** |

对应"碎片→金币"折算：道具池 4💰/片、仓鼠池 5💰/片。
仓鼠池略划算一点，鼓励攒着换大的；但差距只有 20%，不会逼玩家只走一条。

### 5.3 经济自检（为什么不会通胀）

- 一次仓鼠池 60💰，期望产出：77% 单天赋（分解 2）、18% 双（分解 4）、5% 三（分解 6）
  → **期望回收 ≈ 2.6 碎片 ≈ 0.22 次仓鼠抽**（约 13 金币价值），回收率约 22%；
- 要攒够 12 碎片换 1 抽，需 ≈ **4.6 只废鼠**，即先花 ≈ 277💰 抽 4.6 次 → 只能返 1 次；
- 加上转职证（40/75/120）这个主要金币池，抽卡始终是"零花"，不会取代主线。

## 6. 合成（炼妖，v2 去掉保底券）

选主鼠 + 副鼠 → 预览概率 → 消耗 **30💰** → 两只消失，产出新鼠。

| 项 | 规则 |
|---|---|
| 槽1（主鼠本职业天赋） | **100%** 保留，等级取两者较高 |
| 主鼠槽2/3 | 每项 **55%** 保留 |
| 副鼠所有天赋 | 每项 **45%** 保留 |
| 槽位上限 | 3（超出时按等级从高到低取，Ⅲ 优先） |
| 兜底 | 如果一个额外天赋都没继承，返还 **3 碎片**（不是保底券，只是止损） |
| 职业线 | 跟主鼠 |

"双天赋 × 双天赋"合成的期望：额外天赋 ≈ 1.55 条，**约 30% 会掉档**，这是心跳所在。

## 8. 防崩坏

1. 天赋不参与乘区（减伤加法、穿甲按比例无视护甲）；
2. 三天赋 5% 但仍要掷等级，三 Ⅲ 约 0.0002%；
3. 分解回收约 22%，合成有 30% 掉档风险 → 系统无法自循环放大；
4. 敌人不看天赋，只调 `foeScale`；
5. 预期战力增益：单 Ⅲ ≈ +12%、双 ≈ +20%、三 ≈ +30%（约半个转职阶）。

## 11. 实施清单（文件级，动工前对一遍）

**rpg.js（战斗层）**
- `makeUnit()`：从 rat 读 `talents[]`，挂到 `u.talents`
- `hurtFoe()`：`穿甲`（无视护甲比例）、`余烬`（挂 DOT）
- `applyUnitDamage()`：`硬化`（受伤 −%）+ `复苏`（溢出转盾）
- `unitStrike()`：`嗜血`（击杀回血 / 攻速）、`复苏`（治疗 + 盾）
- 新增 `talentTick()`：余烬的 DOT 计时、复苏的 4 秒攻速
- `drawUnitSprite()`：头顶天赋徽章（最多 3 枚）
- `drawIntroOverlay()`：Ⅲ 级播报横条 + 分享按钮

**shop.js（经济层）**
- 删除 `MODS` 与所有 `mod` 相关绘制/购买（`drawOfferCard`、图鉴、队伍卡）
- 新增 `TALENTS` 定义读取、`rollTalents(line)`（槽位 + 等级掷）
- 摇奖机改造成 `drawGachaPanel()`：两个页签（道具 / 仓鼠），各带单抽 / 十连按钮与概率行
- 新增 `decompRat(idx)`、`SHARD` 存档字段、碎片兑换入口
- 新增 `fuseRats(mainIdx, subIdx)` + 预览面板
- 存档 v3：`mod` → 删除，`talents` 补齐，`shard`、`gachaPity` 持久化

**game.json**
- 新增 `rules.talents`、`rules.gacha`、`rules.shard`、`rules.fuse`（结构与 §7 一致）

**测试**
- `tools/talentcheck.mjs`：五个天赋 × 三级的战斗数值是否真的生效（打桩对比）
- `tools/gachacheck.mjs`：1 万抽的分布 vs 声明概率、保底触发、碎片期望
- `tools/fusecheck.mjs`：合成 5000 次的槽位/等级分布、掉档率、兜底触发率
- 回归：`detcheck` / `rtcheck` 在"0/1/2/3 条天赋"四档下的胜率差 ≤ 8%
