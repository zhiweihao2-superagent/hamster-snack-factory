## 要你产出什么
对**每一张截图**给 1–3 条**具体**建议，格式：
```
[02-team] 线索：<看到的问题> 建议：<怎么改> 影响：<高/中/低>
```
重点看这些维度：
1. **信息层级**：一屏里最重要的东西是否最显眼（例如队伍页最该突出"哪只该换"）
2. **对齐与间距**：中文字宽不一导致的错位、按钮基线、卡片内边距
3. **可点区域**：按钮是否够大（≥44px）、相邻误触风险
4. **颜色对比**：暗底上的灰字（如 `#5b5374`）是否可读、禁用态是否太隐形
5. **重复信息**：同一屏里说了两遍的东西
6. **空状态**：仓鼠盒空、图鉴未解锁、技能为空时是否交代清楚
7. **首屏动线**：新手进商店/队伍的第一眼顺序是否合理
