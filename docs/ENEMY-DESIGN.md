# 敌方老鼠：攻击方式与亮点 —— 规划（v1）

> 目标：现在敌人只是"血量 + 平A + 充能条"，长得各有名字、打起来没差别。
> 这份把**每种老鼠的攻击方式、亮点机制、双抗相性、克制手段**定下来，并给出关卡编排与实施清单。

---

## 1. 六种敌方原型

| 原型 | 名称（Ⅰ→Ⅳ阶） | 攻击方式 | **亮点机制** | 物抗 / 魔抗 |
|---|---|---|---|---|
| **crate 破箱** | 纸箱鼠 → 铁箱鼠 → 保险柜鼠 → 金库鼠 | 近战**冲撞**（击退我方 8px） | 头顶箱子，**第一击只能破箱**；破箱后进入「急躁」：攻速 +15% | **25% / 5%** |
| **shell 穿甲** | 抛壳鼠 → 铰钳鼠 → 断牙鼠 → 血牙鼠 | 近战**突刺**（直线打 2 个） | 攻击**穿透 50% 护甲**，专克护盾流 | 15% / 10% |
| **thief 拾荒** | 拾荒鼠 → 弹弓鼠 → 痰盂炮手 → 废料迫击炮 | **远程抛射**（低伤高频） | 每次命中**偷走 2–5 金币**；存活满 15 秒**撤离**并带走赃款，击杀它可夺回 + 赏金 | 5% / **20%** |
| **boss 质检** | 质检机 → 电检机 → 高压检测塔 → 报废熔炉 | **扫描光束**（直线穿透 3 个） | 血量 ≤50% 进入「**超载**」：攻速 +30%、但**物抗 −10%（破绽）** | 18% / 18% |
| **glue 粘胶** | 喷胶鼠 → 补丁鼠 → 焊接鼠 → 焊炉母鼠 | 远程**胶弹**（减速） | 命中让我方**攻速 −15% 3 秒**；每 12 秒给血最少的同伴**回 10% 血**（治疗位） | 5% / **28%** |
| **blast 自爆**（新增） | 引信鼠 → 火药鼠 → 雷管鼠 → 爆破队长 | 低血（≤35%）时**冲向最近我方自爆** | 自爆范围伤害 = 其最大血量的 40%；**必须在引爆前点杀** | 10% / 10% |

**相性设计的意图**

- **物理克**：拾荒（魔抗 20%）、粘胶（魔抗 28%）→ 用物理打更划算；
- **魔法克**：破箱（物抗 25%）、boss 超载前（18/18 均衡）→ 魔法无视护甲穿过箱子；
- 穿甲鼠**逼你别只靠护甲**，得靠治疗/减伤/点杀。

## 2. 表现与预警（让"亮点"能被看见）

| 项 | 做法 |
|---|---|
| **蓄力预警** | 出手前 0.45s，脚下红圈 + 身体闪红（现在充能条太隐蔽） |
| **攻击类型色** | 物理 = 白/橙冲击波；魔法 = 蓝紫；治疗 = 绿环；偷钱 = 金色硬币飞向敌人 |
| **状态图标** | 破箱（箱子图标）· 超载（红色感叹）· 撤离倒计时（沙漏） |
| **战况字幕** | 关键事件单独一行：`拾荒鼠偷走 4 金币` / `质检机 超载！` / `引信鼠开始自爆` |
| **音效** | 复用现有 `hit / hitBig / crit / shield / heal / down`，给自爆加一个低频预警音 |

## 3. 关卡编排（每种亮点都有自己的舞台）

| 关卡 | 主推亮点 | 编排 |
|---|---|---|
| L1 工厂开张 | 破箱 | 只有纸箱鼠：教会"先破箱" |
| L2 订单加急 | **穿甲** | 首次出现抛壳鼠（穿甲），逼玩家用治疗而不是纯盾 |
| L3 挑食订单 | **偷钱** | 拾荒鼠登场，跑掉会扣钱 —— 教"优先点杀" |
| L4 鼠海 | 混编 | 破箱 + 穿甲 + 拾荒混排，检验队伍均衡 |
| L5 质检日 | **boss 阶段** | 质检机提前登场，体验"超载破绽"的爆发窗口 |
| L6 夜班 | **粘胶 + 自爆** | 减速让你打不快、自爆逼你分火力（配合停电禁用大招） |
| 第 7 关起 | 全员精英化 | 轮次缩放，精英（金环）概率随轮次上升 |

## 4. 数值上限（不制造"无解组合"）

1. 每波**最多 1 个"特殊位"**（治疗 / 自爆 / 偷钱 三选一）+ 其余填充，避免叠加；
2. 偷钱有上限：单次 ≤5 金币、单局 ≤25 金币；
3. 自爆伤害 = 目标最大血量的 40%，不秒杀满血单位；且引爆有 1.2 秒预警；
4. 粘胶减速不叠加，只刷新时长；
5. boss 超载是"给玩家的奖励窗口"，不是惩罚；
6. 所有亮点机制由 `rules.enemy.*` 开关控制，方便一键关掉做对照测试。

## 5. 实施改动面

**`game.json`**
```json
"rules": {
  "enemy": {
    "crate": { "boxBreakRage": 0.15 },
    "shell": { "pierce": 0.5 },
    "thief": { "steal": 5, "stealCap": 25, "fleeMs": 15000 },
    "boss":  { "overloadAt": 0.5, "overloadAtk": 0.3, "overloadResP": -0.10, "beamTargets": 3 },
    "glue":  { "slow": 0.15, "slowMs": 3000, "healEvery": 12000, "healPct": 0.10 },
    "blast": { "triggerHp": 0.35, "radius": 70, "damagePct": 0.40, "fuseMs": 1200 }
  }
}
```

**`tools/rpg.js`**
- `foeStrike()` 按 `type` 分流到 6 个攻击函数（冲撞 / 突刺 / 抛射 / 光束 / 胶弹 / 自爆）；
- `telegraph()`：出手前 0.45s 画红圈 + 闪红；
- 状态：`foe.rage / foe.overload / foe.fleeAt / foe.fuseAt`；
- 治疗位：`glueHealTick()` 每 12 秒给友军回血（绿环 + 战况字幕）；
- 偷钱：命中时 `addCoins(-n)`，敌人身上记 `stolen`，击杀返还 + 赏金。

**`tools/shop.js`**
- 图鉴新增**敌人页**：名称 / 攻击方式 / 亮点 / 双抗 / 克制建议；
- 补给站与关卡开场把"本关亮点"写进特色行（现有 `brief`）。

**测试**
- `tools/foecheck.mjs`：逐个原型验证亮点是否生效（偷钱后金币变化、自爆伤害、治疗量、破箱后攻速）；
- 回归：`detcheck` / `rtcheck` L1–L6，确认"特色化"没有把胜率打崩。

## 6. 分期

| 期 | 内容 | 估时 |
|---|---|---|
| **E1** | 承担层：6 个攻击函数的骨架 + 蓄力预警 + 类型色 | 1 天 |
| **E2** | 破箱怒气 / 穿甲 / 拾荒偷钱撤离 | 1 天 |
| **E3** | boss 超载阶段 + 粘胶减速与治疗 | 1 天 |
| **E4** | 新增自爆鼠（含预警与范围伤害） | 半天 |
| **E5** | 图鉴敌人页 + 关卡编排微调 + 配平 | 1 天 |
