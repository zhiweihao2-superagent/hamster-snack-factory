## 迭代记录

**idle-1（5 轮）**

| 轮 | 结果 |
|---|---|

| v2 | 炸药加粗变红、嘴闭；覆盖率 40% 超上限，眼白高光丢失 |
| v3 | 收窄到 30.8%；4 张同批被安全系统按 `violence` 拦过一次，把 `dynamite` 改写成 `party firecracker` 后通过 |
| v4 | **采用**：加"40 格粗像素格 + 眼睛=红块/瞳块/白块"后，覆盖 33–34%、眼睛有白点、炸药分段清楚 |
| v5 | 试"30 格超粗格"，眼睛变死板方块、脸更糊 → 回滚 v4 |

**其余 4 帧（2 轮）**

## 已知问题

1. **`action-windup` / `action-strike` 覆盖率偏高**（36–41%），比 `idle` 高 6–8 个百分点。蹲伏和前倾时四肢收拢、体块重叠，这是姿态本身带来的，不是体型变了。
2. **T2 的 `action-windup` 眼睛偏暗**（12 色是该组最低），做攻击预览时辨识略弱。
3. 脸部精细度仍略逊 `foe-shell-2`（参考直接按 64px 画、约 2px 一格；本批 1254px 降采样、约 1px 一格）。主 agent 已确认按 64px 显示可读，不再压格子。
4. `action-strike` 的"前扑"在 64px 下和 `idle` 差异不算大（前倾 15° 只体现为重心偏移），接入后建议靠位移/特效补动感。
5. 四阶炸药数：1 / 2 / 3 / 5（3 上 2 下），四阶的"5 根"在 64px 下需要数格子才分清，与三阶的直觉差距小于设定。

## 流水线改动（本次新增）

- `pipeline.py`
  - `fit_resize` 的 char 分支：超宽帧改**中心裁剪**（原来横向挤压变形），配合"不为单帧压整组"；
  - `boost_white(thresh)`：亮度 ≥ 阈值的像素压成纯 `#fff8ee`，救眼白高光与牙齿（仅 A2b 开启，阈值 220）；
  - `denoise` 参数：A2 用 3×3 中值，**A2b 关闭**（中值会把 4px 的眼睛糊掉）。
- `build.py`：`group_key` 区分 `A2b`；`GROUP_TARGET_H = {"A2b": 50, "A2": 48}`；`GROUP_MAX_W` 让 A2b 不受宽度约束。
- `sheet.py`：新增 `sheet_A2b`，抽出 `_sheet_charset` 复用。
- `stats.py`：按资产打印色数/覆盖/身高汇总。
