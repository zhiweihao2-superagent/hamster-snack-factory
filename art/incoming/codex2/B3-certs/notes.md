# B3 · 转职证图标（4 个，16×16 + 32×32）

## 产出

| 文件 | 阶 | 徽章 |
|---|---|---|
| `cert-1` | 一转证 | 青铜圆牌 + 1 颗大金星 |
| `cert-2` | 二转证 | 白银圆牌 + 2 颗金星 |

- 终版：`_tools/p_B3_fix.txt` —— 改成"深色金属圆牌 + 亮金星星"，并要求四阶只靠金属色与星数拉开。

| 轮次 | 结果 |

| 第 1 版 | 4/4 落盘，但奶油纸 + 淡黄星在 16px 下糊成一片米色，四阶看不出差别 → 判为不合格 |
| 第 2 版 | 4/4 落盘，改为深色圆牌 + 亮金星，金属色随阶递进（青铜→白银→黄金→深红）→ 采用 |

## 已知问题

1. **16px 下星数不够读**：一转 1 颗星清楚，二至四转的 2/3/4 颗星各只有 2–3px，靠数星星分辨吃力。
   实际辨识主要靠**金属色**（青铜 / 白银 / 黄金 / 深红），这在 16px 下是清楚的。
   若游戏内必须靠星数区分，建议改用 32px 档，或在图标旁加罗马数字文本（文本是 UI 层的事，不在这批美术里）。
2. 牌面高光弧在 16px 下几乎不可见，属装饰性细节，可接受。
3. 挂绶带在 16px 下只剩顶部两小块，主要形体是圆牌。
