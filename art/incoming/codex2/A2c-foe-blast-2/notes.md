# A2c · 引信鼠「硬像素」版（foe-blast 1–4 阶）

> 起因：用户否了 A2b 的观感——「全糊到一起了」。诊断结论不是体型/朝向，而是**像素不干净**：
> 眼睛糊成一坨、脸是灰雾、没有硬描边。A2b 的原图本身没有 2px 硬边特征，降采样后中间调全留着。
> A2c 改为**提示词逐条写死硬像素 + 后处理直接塌成固定色**，用户已确认风格通过。

## 用户已确认的两个取舍

1. **描边 2px**：`32×32 grid, every pixel as a 2×2 block` ⇒ 网格里 1 pixel = 画布上 2px。
2. **8 色**：6 色 + 白 `#fff8ee`（眼白/牙齿）+ 亮红 `#e8402c`（眼睛，与炸药暗红区分）。

## 后处理

`_tools/build_a2c_all.py`（批量）与 `build_a2c.py`（单张出候选）：

| 步骤 | 做法 |
|---|---|
| 中值滤波 | **关**（会把 4px 的眼睛糊掉） |
| 量化 | **跳过**，`pipeline.quantize_fixed()` 把每个像素直接塌到固定调色板最近色 |
| 描边 | `enforce_outline(width=2)` |
| alpha | 二值化 + 3×3 去孤立像素 |
| 锚点 | 身高锁 50px；`hop-air` 脚底 y=52，其余 y=61；水平居中 |

`quantize_fixed()` 是本次新增：原图的抗锯齿中间调被全部塌成平面色，边缘自然变硬——这是「不糊」的关键。

## 已知问题

1. **T4 的引信形态**与其他三阶不一致：T1–T3 是竖向小火苗，T4 因为炸药包大、引信画成了顶部一段黄色横条，观感更像「金色封条」。功能上仍是引信。
2. **T2 的炸药是竖向两根**，T1/T3/T4 是横向排布，四阶之间炸药朝向不完全统一。
3. **T4 覆盖 37.8%**，比另外三阶高约 3 个点——炸药包本来就大。
4. 脸部没有腮红、胡须等细节，这是「不许小于 2×2 的细节」的必然结果，与 `foe-shell-2` 的繁简度有差别。
