# 敌方老鼠动画素材：试接包 v4

五条路线、各四个等级，共 20 套角色。每套含五张 64×64 RGBA PNG 与一个放大预览 GIF；一级到四级沿用角色 ID 后缀 1～4。

## 分类
- crate：箱鼠
- shell：金属鼠
- thief：拾荒鼠
- boss：机械鼠
- glue：工坊鼠

## 帧名与播放
- 待机：idle-1、idle-2；
- 攻击：action-windup、action-strike；
- 蹦跳：hop-air + idle-1（落地复用）。

PNG 为原尺寸；GIF 为放大预览。推荐使用最近邻采样，动作时长及角色锚点需在游戏内调整。

## 本包来源与注意事项
- 采用毛色降噪后的角色帧；箱鼠等级使用统一的二级本体和不同头部装备。
- shell-4 与 boss-4 为后来重绘的四级版本。机械鼠四级源图的第 1、4 帧曾贴近分隔边界，装备边缘需在实机复查。
- 部分角色等级之间还未做到本体逐像素分层锁定；部分装备与原交接单的具体描述有差异。除箱鼠外，不承诺转职等级之间的身体逐像素一致。
- 所有 PNG 已检查：64×64、alpha 为 0 或 255、每帧不超过 36 色。尚未接入实际小游戏或做手机实测。
