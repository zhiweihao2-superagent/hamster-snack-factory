# 五职业仓鼠动画接入说明

此包为游戏内试接稿：五个职业、每个三个等级，共 15 套；每套五张 64×64 RGBA PNG，alpha 为 0 或 255。

## 目录

- `tank` 盾牌鼠；`blade` 近战鼠；`shot` 远程鼠；`hex` 魔法鼠；`care` 医师鼠。
- 每个职业中的 `*-2`、`*-3`、`*-4` 分别是本次预览图中的基础形态、二转、三转。编号沿用美术交接单，不代表其他工程中的职业 ID 必然相同。
- 每套另有 `preview.gif` 供查看，实际接入使用 PNG。

## 帧及播放建议

- 待机：`idle-1.png` ↔ `idle-2.png`，建议每帧约 400 ms。
- 攻击或施法：`idle-1.png` → `action-windup.png` → `action-strike.png` → `idle-1.png`，建议起手 180～220 ms，落手 180～280 ms。
- 蹦跳：`idle-1.png` ↔ `hop-air.png`，落地复用待机 1；建议每帧约 200～250 ms。
- 时间为预览建议，游戏可调整；仓鼠应向右运行。像素图在引擎中请使用最近邻采样，并自行检查角色锚点。

## 使用前核对

这是试接稿，转职前后的身体尚未逐像素锁定，部分装备与原始美术交接单存在设计差异。部分源图拆帧曾出现边界贴近提示；魔法三转落手帧尤其需在游戏内检查。尚未在微信小游戏工程中做实机适配。请根据游戏实际表现调整锚点、动作时长和边缘像素。
