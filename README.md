# 仓鼠零食工厂

5×5 三消小游戏，单文件 HTML5，没有任何依赖，双击 `index.html` 就能玩。

## 怎么玩

- 点两个相邻的零食交换位置，横竖凑成三个以上就消掉，掉下来的会补满。
- 一局五关，每关有步数上限和进度目标（40 / 74 / 82 / 118 / 132，步数 5 / 6 / 6 / 7 / 7）。
- 掉落引起的连锁不花步数，连锁越深进度加得越多，屏幕上会飘「连击 ×N」。
- 没步数或没可行交换时不会卡死：无解自动重排，不扣步。

## 礼盒与三样工具

每关通关后从礼盒里挑一样带走，三样都是**主动技能，不花步数**，点一下就用：

| 工具 | 用法 | 效果 |
|---|---|---|
| 打包机 ×1 | 先点按钮，再点盘上一格 | 那一整行 + 一整列一起清掉 |
| 打包仓鼠 ×2 | 直接点按钮 | 盘上最多的那种零食，从最大一堆开始啃，共 10 格 |
| 大礼盒 ×1 | 先点按钮，再点盘上一格 | 以该格为中心的 5×5 全炸开 |

礼盒剪影会随本局进度从下往上填满；一局结束显示完整礼盒和最大单次进度。

## 自己改

全部逻辑与绘制都在 `index.html` 里的一个 `<script>` 中，关键位置：

- `TYPES` / `PATTERNS`：三种零食与三张礼盒图案。
- `LEVELS`：五关的步数与目标。
- `TOOLS` / `PACKS`：三样工具与过关三选一。
- `resolveRound()` / `commitClear()`：一次消除的算法。
- `drawBoard()` / `drawBottom()` / `drawPick()`：棋盘、工具条、三选一的绘制。

改完直接用浏览器打开就能看，不需要构建。

## 调试接口

页面里挂了一组 `window.__*` 钩子（`__gameState`、`__testRun`、`__toolProbe`、`__toolStage` 等），给无头浏览器跑回归用。跑一批：

```js
window.__testRun(20)              // 20 局，返回胜率、每关到达数、平均连锁
window.__testRun(20, 20261120, false)  // 同一批种子，但不使用工具（对照组）
```

## 已知取舍

- 打包仓鼠原本是「最多那种零食全清」，实测一次 +140 直接通关，所以封顶 10 格。
- 关卡目标比策划原稿（12/25/28/38/50）提高了不少：按原值跑 20 局全胜、每关两步就过，没有难度可言。
